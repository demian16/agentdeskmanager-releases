# AgentDeskManager — releases

Instaladores de **AgentDeskManager** para Windows. Este repo solo publica versiones: el código es privado.

- Descargá el último `AgentDeskManager-Setup-<versión>.exe` desde [Releases](https://github.com/demian16/agentdeskmanager-releases/releases/latest).
- Una vez instalada, la app busca versiones nuevas acá sola (al iniciar y cada 4 horas) y ofrece reiniciar para actualizarse.
